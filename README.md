# 🏥 Disease Prediction System

## 📌 Project Overview

The Disease Prediction System is a Python and Machine Learning based desktop application developed using Tkinter and MySQL.

It predicts possible diseases based on patient symptoms and stores patient information and prediction history in a MySQL database.

## ✨ Features

- Patient Information Management
- Symptom-Based Disease Prediction
- Machine Learning Model Integration
- Patient History Management
- Reports and Analytics Dashboard
- Disease-wise Prediction Charts
- Daily Prediction Trends
- MySQL Database Integration

## 🛠️ Technologies Used

- Python
- Tkinter (GUI)
- MySQL
- Machine Learning
- Scikit-learn
- Pandas
- Matplotlib

## 🦠 Diseases Covered

- Flu
- Common Cold
- Malaria
- Stomach Infection

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/vaishanaviraut49-hash/Disease_Prediction_system.git
```

2. Open the project folder:

```bash
cd Disease_Prediction_system
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Configure your MySQL database and update the database connection settings using your own local credentials.

5. Run the application:

```bash
python main.py
```

## 📊 Reports and Analytics

The application provides:
- Total patient count
- Total prediction count
- Disease-wise prediction statistics
- Disease percentage chart
- Daily prediction trend

## 🎯 Project Objective

To develop a simple desktop-based application that demonstrates how Machine Learning can be used for symptom-based disease prediction and patient record management.
